# Dashboard TRM

Página web que consulta en vivo la Tasa Representativa del Mercado (TRM) de Colombia desde la API de datos abiertos ([datos.gov.co](https://www.datos.gov.co/resource/32sa-8pi3.json)).

- Histórico de los últimos 2 meses con valores máximo, mínimo, promedio y variación.
- Navegación en el tiempo (períodos de 1 mes a 5 años, o fechas personalizadas, desde 1991).
- Aviso cuando la API no responde, con opción de reintentar.
- Sección "¿Cuándo comprar dólares?": análisis técnico del último año más el tono de noticias recientes (GDELT). Es informativo, no es asesoría financiera.

No requiere servidor ni instalación: basta con abrir `index.html` en el navegador.
